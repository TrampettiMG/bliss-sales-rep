# Bliss Sales Rep

Stage A spike: proves that a rep can point CoWork at this public repo and end up with a personalized, working Claude setup — before the real 10 sales tools get built.

- `CLAUDE.md` — persona, house rules, first-run profile onboarding (self-deletes after first run).
- `skills/lead-ideas/` — one dummy tool proving a skill loads and reads the rep's profile.
- `SETUP-CARD.md` — the one-page install steps for a non-technical rep.

No customer, QuickBase, or Trampetti-internal data belongs in this repo. Public repo — scrub before every push.
