# Bliss Sales Rep — Setup Card

Follow these steps in order. It should take about 5-10 minutes.

1. **Turn off training data sharing** in your Claude account settings, if you haven't already. (Ask your trainer if you're not sure where this is.)
2. **Open the Claude app** and select **Cowork** mode (next to Chat, above the message box).
3. Click **"Project or folder" → New project**. Name it **Bliss Sales Rep**. Leave "Use a folder" alone — you don't need one. Click **Create project**.
4. In the message box, paste exactly this and send it:

   ```
   Set yourself up using https://raw.githubusercontent.com/TrampettiMG/bliss-sales-rep/main/CLAUDE.md
   ```

5. Claude will ask you 5 quick questions (name, territory/counties, product focus, phone or email, and anything else useful). Answer them in plain language, one message.
6. Claude will confirm setup is done. Try typing: **"give me lead ideas for my county."**
7. From now on, just start new chats inside this same **Bliss Sales Rep** project — you never need to paste that link again.
8. If something doesn't work, stop and tell your trainer — don't try to fix it yourself.

That's it — you're set up.
